## Features

This interactive mockup demonstrates:

✅ **5 Key Screens:**
1. Login Page
2. Teacher Dashboard
3. Grade Entry Interface
4. Student Result View
5. Grading Configuration Settings

✅ **Interactive Elements:**
- Working navigation between screens
- Functional login (demo logins available)
- Grade entry with real-time calculation
- Modal dialogs
- Toast notifications
- Form inputs with validation
- Responsive buttons and cards

✅ **Design System:**
- Complete color palette (primary, success, warning, error, grays)
- Typography scale (6 sizes + weights)
- Spacing system (8px base unit)
- Component library (buttons, forms, cards, tables, modals, toasts)
- Accessibility-compliant (WCAG 2.1 AA)

## Quick Demo Logins

Click the demo buttons on the login page:
- **Teacher**: View dashboard and grade entry
- **Student**: View results and download report card
- **Admin**: View all features including settings

Or use keyboard shortcut after login:
- `Alt + D` - Dashboard
- `Alt + G` - Grade Entry
- `Alt + R` - Results
- `Escape` - Close modal
